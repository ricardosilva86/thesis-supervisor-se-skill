# Rubrica: Prontidão para Defesa

Pontue 0 = não consegue responder, 1 = responde parcialmente, 2 = responde com evidência e limite explícito. Use os itens com nota 0 para orientar ensaio e revisão final.

| Tema | Pergunta de banca | Evidência que a resposta deve citar | Nota |
| --- | --- | --- | --- |
| Problema | Qual problema específico e para quem? | charter, contexto e referências | |
| Lacuna | O que falta no estado da arte? | revisão e comparação de alternativas | |
| Contribuição | O que seu trabalho acrescenta? | contrato de contribuição e claim | |
| Método | Por que este desenho responde à RQ? | protocolo e unidade de análise | |
| Baselines | Por que essa comparação é justa? | plano experimental e orçamento | |
| Dados | Como foram selecionados, rotulados e limitados? | dataset/benchmark card | |
| Métricas | Por que essas métricas representam sucesso? | definição operacional | |
| Resultados | Que evidência suporta o claim principal? | tabela/figura, scripts e ledger | |
| Validade | Qual ameaça mais séria permanece? | registro de ameaças e mitigação | |
| Reprodutibilidade | Como outra pessoa executa a avaliação? | manifesto e teste em ambiente limpo | |
| Limites | Onde a solução não funciona ou não foi avaliada? | discussão e claims ledger | |
| Ética/governança | Quais riscos e autorizações se aplicam? | política, registros e decisões | |

## Simulação

Para cada pergunta, responda em até 90 segundos: afirmação, evidência, limite e implicação. Se a resposta depender de algo não registrado, crie uma pendência no ledger ou no registro de riscos.
