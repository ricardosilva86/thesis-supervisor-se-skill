# Rubrica: Interpretação de Resultados

Use esta rubrica antes de escrever Resultados, Discussão e Conclusão. Pontue 0 = ausente/problemático, 1 = parcial, 2 = suficiente.

| Dimensão | 0 | 1 | 2 | Evidência/observação |
| --- | --- | --- | --- | --- |
| RQ → resultado | tabela sem RQ | relação implícita | cada RQ aponta para resultado específico | |
| Resultado → claim | números soltos | claim aproximado | claim com escopo é respondido explicitamente | |
| Baseline | sem comparação justa | baseline limitado | comparador e recursos justificados | |
| Incerteza | só melhor valor/média | variância parcial | distribuição, intervalos ou repetições adequadas | |
| Relevância prática | só significância ou ranking | impacto mencionado | trade-offs, custo e magnitude interpretados | |
| Análise de erros | ignorada | exemplos anedóticos | categorias, falhas e casos negativos analisados | |
| Explicações rivais | ausentes | uma limitação genérica | confundidores e alternativas discutidos | |
| Escopo | generalização excessiva | limites no final | conclusão limitada a dados, contexto e método | |

## Checklist de escrita

1. Comece pela RQ, não pela tabela.
2. Diga o que foi observado, depois a inferência permitida.
3. Diferencie ausência de evidência de evidência de ausência.
4. Diga o que a proposta perde, custa ou não resolve.
5. Atualize o `claims-ledger.md`: suportado, inconclusivo, refutado ou removido.

Evite linguagem causal se o desenho não controla explicações alternativas.
