# Rubrica: Pergunta de Pesquisa

Pontue cada dimensão como 0 = ausente/problemática, 1 = parcial, 2 = suficiente. O objetivo não é obter uma nota automática; é tornar lacunas explícitas.

| Dimensão | 0 | 1 | 2 | Evidência/observação |
| --- | --- | --- | --- | --- |
| Relevância | benefício não definido | contexto genérico | impacto e público delimitados | |
| Lacuna | tema apenas | lacuna alegada | lacuna sustentada por fontes | |
| Precisão | termos vagos | parte dos termos definidos | população, intervenção/fenômeno e resultado definidos | |
| Testabilidade | opinião ampla | medida possível mas indefinida | evidência e critério de resposta definidos | |
| Unidade | ausente | implícita | unidade de análise explícita | |
| Escopo | ilimitado | fronteiras parciais | contexto, período e exclusões definidos | |
| Viabilidade | depende de suposições | recursos parcialmente conhecidos | dados, acesso e prazo plausíveis | |
| Ética/governança | ignorada | riscos listados | autorizações e mitigação encaminhadas | |

Antes de avançar para G2/G3, trate dimensões com zero como bloqueios ou registre-as como riscos explícitos.
